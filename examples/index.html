🎬 FBX 3D 웹서비스 · 실습 예제

← 강의 프리젠테이션으로 돌아가기

아래 순서대로 진행하세요. 각 단계는 이전 단계 위에 기능을 하나씩 쌓아갑니다.

1

3D 기본 씬

Scene · Camera · Renderer · Light · OrbitControls (마우스로 회전·확대)

▶
2

캐릭터 FBX 불러오기

FBXLoader로 캐릭터를 씬에 세우기 (아직 T자 정지 자세)

▶
3

애니메이션 입히기

별도 FBX의 동작을 AnimationMixer로 캐릭터에 적용·재생

▶
4

제어 UI 완성

재생/정지 · 애니메이션 전환(크로스페이드) · 속도 · 타임라인

▶
5

파일 불러오기 인터페이스

사용자가 직접 FBX 선택·드래그&드롭 (캐릭터/애니메이션 자동 인식)

▶
⚠ 이 예제들은 FBX 파일을 읽기 때문에 로컬 웹 서버에서 실행해야 합니다. (파일을 더블클릭한 file:// 방식은 보안정책으로 모델 로딩이 막힙니다.)
실행: 프로젝트 폴더에서 python -m http.server 8000 또는 npx serve . → http://localhost:8000/examples/ 접속.
모델 파일 위치: ../fbx/character.fbx, ../fbx/walk_ani.fbx
GLB 변환본: ../glb/character.glb, ../glb/walk_ani.glb
